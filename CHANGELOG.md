# 1.1.0-beta.1

- Book-first visual menus, sample previews, configurable appearance, and opt-in WHEN/IF/DO rule editing.
- Companion browser pairing, installation credentials, durable acknowledgements/replay, and optional event permissions.
- Optional Bits/rewards/raids/follows/Hype Trains/results/moderator/VIP/chat/moderation events and expanded Minecraft actions.
- Persistent priority queue, thresholds, weighted actions, combo coalescing, local effect tests, and explicit safety settings.
- Live/archive chests, selected book recipient, signs, supporter walls, Text Displays, button pulses, and named keepsakes.
- Independent profiles, delegated access, safe preset import/export, user-ID supporter registry, and name moderation/filtering.
- Public saved-event observers and datapack event storage.
- Self-hostable Companion 0.1.0 source, optional broadcaster-account chat interface, and current-subscriber recovery.
- Public cloud hosting, dedicated-bot authentication, full historical recovery, and real-account/gameplay acceptance remain outside this preview.

# 1.0.0

- Book-only defaults: extra sounds, messages, and functions require explicit rule configuration.

- Fabric and NeoForge targets for Java Edition 1.21.1 through 26.3, plus a Paper server plugin.
- Twitch public-client device sign-in, token rotation/validation, and live EventSub subscriptions.
- Durable subscriber history, duplicate detection, channel isolation, supporter summaries, and recoverable written books.
- Live inventory/lectern books with automatic page creation and archive volumes.
- Subscription, resubscription-message, and gifted-recipient rules with messages, sounds, and datapack functions.
- Effect cooldowns and a bounded pause/resume queue that never applies its limits to recorded names.
- Common-library, Twitch-protocol, and plugin behavior tests; native Minecraft book smoke checks.
