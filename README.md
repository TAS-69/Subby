# Subby

**Your Twitch subscribers. In your Minecraft book. Automatically.**

Minecraft **1.21.1–26.3** · **Fabric · NeoForge · Paper**

**Twitch subscription → Subby Companion → a name in your book**

Subby records new subscribers, gift recipients and shared resubscription messages. Pages and volumes grow automatically. Carry your book, put it on a lectern, or recover it if it gets lost.

<div align="center">

## Get your first book

</div>

1. **Install** the JAR for your Minecraft version and platform.
2. **Set the host first:** open `/subby` → **Advanced → Connection settings → Companion address** and enter your self-hosted Companion URL.
3. **Connect:** run `/subby connect`, sign in with Twitch, then choose **Get your subscriber book** in `/subby`.

Self-hosting [Companion](https://github.com/TAS-69/Subby-Companion/wiki/Hosting) is expected. The default `localhost` address works only when Minecraft can reach Companion on the same computer. [Step-by-step setup →](https://github.com/TAS-69/Subby/wiki/Getting-started)

| Platform | Where it goes |
| --- | --- |
| Fabric | `mods` — also install the matching Fabric API |
| NeoForge | `mods` — use the matching loader |
| Paper | `plugins` — one JAR covers the supported range |
